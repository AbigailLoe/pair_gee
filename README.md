# pair_gee
Code and simulated data for reproducing results for second thesis project, currently submitted to Biometrics Methodology.

Files `simulated_data_*.csv` contain simulated datasets, with weights already calculated, and fit via `adler_rf.R`.

The random forest weights may be calculated using the `adler_rf.R` file, while a worked data example is found in `TBI_sad.R`

The CareQoL data that were used in data application are available from the authors upon reasonable request. Due to privacy reasons and human research subject ethics, they may not be posted on GitHub or shared in supplemental materials. We hope readers of this file understand, and find the worked data example of interest anyway.
